# 002 - Config Tracking Strategy

## 决定

Mahou 不默认版本控制根目录 `config/` 中由第三方 Mod 生成的配置。

当前仅保留：

`config/ftbquests/`

因为其中保存的是 Mahou 主动制作的任务内容。

## 原因

目前项目尚未开始系统调整第三方 Mod 的配置参数。

Git 历史显示，大量普通 Mod 配置是在开发任务线和维度时一起进入仓库的，并没有明确证据表明这些配置是 Mahou 主动设计和维护的内容。

继续全部跟踪会导致：

- 游戏启动时大量自动修改污染 `git status`
- 本地客户端状态进入仓库
- 难以区分哪些配置真正属于 Mahou 的设计

## 后续原则

当项目明确修改某个 Mod 配置时，再将对应配置从 `.gitignore` 中单独放出并加入 Git。

因此：

默认状态：

`第三方 Mod config → 本地文件`

明确成为 Mahou 设计的一部分后：

`第三方 Mod config → Git 跟踪`

目录和配置的管理范围随项目实际需求逐步扩大，而不是提前纳管所有自动生成内容。
